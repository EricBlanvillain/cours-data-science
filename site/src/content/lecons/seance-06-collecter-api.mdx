## Lire la réponse

`requests.get` envoie l'URL et rapporte la réponse : d'abord un code, 200 si tout va bien, 404 si ce que tu demandes n'existe pas, puis du JSON, que `.json()` transforme en dictionnaire. Le JSON est souvent imbriqué : on descend marche par marche.

```python
pikachu = requests.get("https://pokeapi.co/api/v2/pokemon/pikachu", timeout=10).json()
pikachu["types"][0]["type"]["name"]     # "electric"
```

<details>
<summary>Les unités de la PokéAPI</summary>

Dans la PokéAPI, `height` est en décimètres et `weight` en hectogrammes : Pikachu mesure 0,4 m et pèse 6 kg. Lire la documentation d'une API, c'est aussi apprendre ses unités.

</details>

## Des appels, un tableau

Un appel donne une fiche ; une boucle en donne cinq. Chaque fiche devient un dictionnaire, la liste de dictionnaires devient un tableau pandas. Entre deux appels, une petite pause : une API gratuite n'aime pas qu'on la bombarde.

| Le geste | En Python | Pourquoi |
|---|---|---|
| Demander | `requests.get(url, params=..., timeout=10)` | les paramètres précisent la commande |
| Vérifier | `reponse.raise_for_status()` | un 404 devient une erreur qu'on attrape |
| Lire | `reponse.json()` | du texte JSON au dictionnaire |
| Ranger | `pd.DataFrame(lignes)` | une liste de dictionnaires, un tableau |
| Garder | `tableau.to_csv("donnees.csv", index=False)` | ne pas tout redemander |

## Quand ça rate

Pas de réseau, site en panne, nom mal écrit : un appel peut échouer. La fonction `demander` du notebook enveloppe l'appel dans un `try / except` et renvoie des données de secours écrites à l'avance : le notebook va au bout, et on le sait.
