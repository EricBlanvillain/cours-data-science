## La boucle

La règle est écrite dans le prompt système : pour utiliser un outil, réponds `OUTIL: nom(arguments)`. La boucle Python repère cette ligne, exécute la fonction et renvoie le résultat au modèle.

<summary>Deux outils à la suite</summary>

« Combien fait la vitesse de Pikachu fois 3 ? » demande deux étapes : chercher la vitesse, puis calculer. Lancé pour de vrai, le petit modèle a écrit « calculer(348 * 27) », sans « OUTIL: » et avec les nombres de l'exemple du prompt : rien ne s'est exécuté. Le mode démo du notebook, des réponses écrites à la main, montre ce que la boucle doit faire : `chercher_pokemon(Pikachu)`, qui renvoie une vitesse de 90, puis `calculer(90 * 3)`, qui renvoie 270.

## Les bonnes pratiques avec l'IA

Savoir comment ça marche change la façon de s'en servir.

| La pratique | Pourquoi |
|---|---|
| Vérifier une date, un chiffre, une citation | Le modèle écrit le plausible, pas le vrai |
| Ne rien taper qu'on n'écrirait pas sur un mur public | Ce qu'on envoie peut être stocké et relu |
| Faire faire les calculs par Python | Le modèle écrit des chiffres, il ne pose pas l'opération |
| Se faire expliquer plutôt que copier | Le test : sais-tu le refaire sans lui ? |
| Garder la main sur envoyer, payer, effacer | Un agent bien construit demande avant les actions importantes |

### À toi : ton agent, ton outil

Donne à l'agent un outil à toi, sur un sujet qui t'intéresse, puis mesure s'il sait s'en servir.

- **Écris la fonction-outil** et teste-la seule, sur deux cas, dont un qui rate.
- **Ajoute-la à `OUTILS` et décris-la dans le prompt système**, avec un exemple d'appel : le modèle ne connaît que ce qu'on lui décrit.
- **Écris un banc de quatre questions**, dont une qui n'a besoin d'aucun outil, puis note le score et une question ratée.
