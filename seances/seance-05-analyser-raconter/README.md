- 60 min : notebook `05_analyser_raconter.ipynb`

- 15 min : chacun présente son dashboard en 2 minutes chrono, les autres jouent le client

Si le temps manque : on s'arrête au dashboard (section 7) et le pitch se prépare à la séance suivante. C'est une séance qui déborde souvent : prévoir la reprise dès le calendrier.
