# Séance 3 · SQL et Git, les outils du quotidien · ⭐

Niveau : ⭐ Débutant

Bloc 1 · Les bases solides

Objectifs : comprendre où sont stockées les données d'une appli et interroger une base SQLite en SQL (SELECT, WHERE, ORDER BY, GROUP BY, un premier JOIN) ; comprendre pourquoi les développeurs versionnent leur travail et pousser son projet de la séance 2 sur GitHub avec un README.

Déroulé (2h)
- 20 min : où sont stockées les données d'une appli, tables et SQL (section 1 du notebook `03_sql_et_git.ipynb`) ; Git et GitHub avec l'analogie de la sauvegarde de jeu vidéo, les 4 commandes add / commit / push / pull (section 6)
- 30 min : sections 2-5 : SELECT / WHERE, ORDER BY, GROUP BY, JOIN avec une petite table `types` (forces / faiblesses), sur le dataset Pokémon chargé dans SQLite en mémoire
- 20 min : section 6 : chacun pousse son notebook de la séance 2 sur son dépôt depuis Colab (Fichier → Enregistrer une copie sur GitHub) et écrit son README (généré par le notebook, à coller sur GitHub)
- 30 min : section 7, projet : mini-défi « même question en SQL et en pandas », 3 fois, avec une fonction qui vérifie que les deux réponses concordent ; puis on pousse aussi ce notebook
- 20 min : partage : chacun montre son dépôt GitHub (notebook, README, historique des commits) et sa question bonus
