# Séance 3 · SQL et Git, les outils du quotidien · ⭐

Niveau : ⭐ Débutant

Bloc 1 · Les bases solides

Objectifs : comprendre où sont stockées les données d'une appli et interroger une base SQLite en SQL (SELECT, WHERE, ORDER BY, GROUP BY, un premier JOIN) ; comprendre pourquoi les développeurs versionnent leur travail et pousser son projet de la séance 2 sur GitHub avec un README.

Déroulé (1 h 30)
- 15 min : où sont stockées les données d'une appli, tables et SQL (section 1 du notebook `03_sql_et_git.ipynb`) ; Git et GitHub avec l'analogie de la sauvegarde de jeu vidéo, les 4 commandes add / commit / push / pull
- 60 min : notebook `03_sql_et_git.ipynb`
  - sections 2-5 (25 min) : SELECT / WHERE, ORDER BY, GROUP BY, JOIN avec une petite table `types` (forces / faiblesses), sur le dataset Pokémon chargé dans SQLite en mémoire
  - section 6 (15 min) : chacun pousse son notebook de la séance 2 sur son dépôt depuis Colab (Fichier → Enregistrer une copie sur GitHub) et écrit son README
  - section 7 (20 min) : projet, mini-défi « même question en SQL et en pandas », avec la fonction qui vérifie que les deux réponses concordent
- 15 min : partage : chacun montre son dépôt GitHub (notebook, README, historique des commits) et sa question bonus

Si le temps manque : on s'arrête après le premier des trois mini-défis (section 7), les deux autres ouvrent la séance suivante. Le push GitHub (section 6) se termine en séance : c'est le livrable du bloc 1.

Entre deux séances (à la maison) : `03_exercices.ipynb` — 12 exercices ⭐ à ⭐⭐⭐ avec vérification automatique (✅/❌), indices et solutions dépliables. C'est le seul travail personnel : la leçon, elle, se fait toujours ensemble.
