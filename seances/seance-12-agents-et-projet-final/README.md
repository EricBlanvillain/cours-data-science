# Séance 12 · Les agents, et le projet final · ⭐⭐⭐

Niveau : ⭐⭐⭐ Avancé

Bloc 4 · Comprendre et construire avec l'IA générative

Objectifs : comprendre ce qu'est un agent (un LLM qui agit en appelant des outils), en construire un sans framework avec 3 outils Python (fichier Pokémon, calculatrice sécurisée, RAG de la séance 11), voir ce qui peut rater, fixer les bonnes pratiques avec l'IA, puis finaliser son portfolio GitHub et préparer la présentation finale.

Déroulé (2h)
- 20 min : un agent = LLM + outils + boucle (le stagiaire brillant à qui on donne un téléphone et une calculatrice), démo d'un agent qui choisit d'aller chercher dans le RAG, les 4 bonnes pratiques
- 15 min : notebook `12_agents_et_projet_final.ipynb`, sections 1 à 3 (le modèle invente et calcule mal, les 3 outils, la boucle `OUTIL: nom(args)`)
- 15 min : sections 4 à 6 (agent → RAG → réponse, banc de test des ratés, quiz des bonnes pratiques)
- 50 min : projet final : check-list du portfolio (4 projets), README généré, fiche projet, répétition à deux avec le gabarit de présentation
- 20 min : présentations finales (3 min chacun) devant le groupe et les invités

Outils (gratuits)
