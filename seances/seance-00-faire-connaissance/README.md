# Séance 0 · Faire connaissance · ⭐

Niveau : ⭐ Débutant

Avant le Bloc 1 · Prise de contact

Objectifs : comprendre le niveau réel de chacun (langages vus, projets faits), noter ce qu'ils ont envie de construire, et vérifier que Python répond dans Colab avec les trois comptes créés.

Déroulé (2h)
- 20 min : tour de table (langages vus, projets réalisés, outils déjà utilisés : ChatGPT ? Roblox Studio ? Scratch ? Minecraft mods ?) et présentation du parcours en 4 blocs
- 15 min : notebook `00_faire_connaissance.ipynb`, sections 1-2 : diagnostic Python en 6 mini-exercices auto-vérifiés (✅/❌), pas noté, juste pour calibrer
- 15 min : sections 3-4 : dictionnaires, puis brainstorm de projets (chacun écrit 3 idées dans une liste Python ; elles servent à choisir les datasets des blocs suivants)
- 15 min : section 5 : check-list des comptes Google Colab, Kaggle, GitHub, et création du premier dépôt `mon-portfolio-ia`
- 35 min : section 6, projet : le jeu du nombre mystère (version « coups prédéfinis », stratégie du milieu, puis une amélioration au choix : chaud/froid, essais limités, score)
- 20 min : partage : chacun montre son amélioration du jeu et son idée de projet préférée

Liens

- Kaggle : https://www.kaggle.com
